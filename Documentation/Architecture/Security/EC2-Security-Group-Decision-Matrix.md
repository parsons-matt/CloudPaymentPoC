| Decision area | Implementation / decision | Justification | Limitations |
|---|---|---|---|
| Inbound SSH | Allow SSH (TCP port 22) from the approved infrastructure administrator's source | Restricts administrative connections to an approved source | Source IP restrictions do not replace identity authentication or access controls |
| Inbound HTTPS | Allow HTTPS (TCP port 443) from approved merchant/bank endpoint IPs where those endpoints connect directly to the instance | Restricts inbound connections to known source addresses | IP addresses can change; source IP filtering alone does not verify sender identity |
| Outbound HTTPS | Allow HTTPS (TCP port 443) to approved destination IPs required by the application | Restricts outbound connections to intended destinations | Destination IP changes require maintenance; port 443 alone does not establish destination trust |
