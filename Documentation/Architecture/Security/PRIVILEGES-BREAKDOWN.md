| Privilege Level | Description |
|---|---|
| AWS Administrator | Permissions to manage specified AWS services and resources. |
| Domain Admin | Manages an assigned functional domain, such as security, infrastructure, or payment processing. Cannot make changes outside that domain. |
| Elevated Privileges | Performs designated sensitive tasks, subject to strong limits, review, and approval requirements. |
| Emergency Privileges | Provides temporary, highest-level access to restore or secure the environment during an emergency. Requires strong authentication, time limits, alerting, and post-use review. |
| Acceptance Privileges | Reviews and approves designated changes or exceptions. The approver cannot approve their own request or perform the change they are approving. |
| No Privileges | Read-only access to explicitly permitted information, such as configurations, findings, and audit records. Cannot modify settings or approve changes. |
